# 🔢 Contador

Um contador interativo desenvolvido com **HTML, CSS e JavaScript**, com uma interface simples e moderna. O projeto permite aumentar, diminuir e zerar o valor exibido, além de incrementar ou decrementar continuamente enquanto o botão estiver pressionado.

## ✨ Funcionalidades

- ➕ **Aumentar:** incrementa o contador enquanto o botão estiver pressionado.
- ➖ **Diminuir:** decrementa o contador enquanto o botão estiver pressionado.
- 🔄 **Zerar:** redefine o valor do contador para zero.
- 🎨 **Interface moderna:** layout centralizado, tema escuro e botões interativos.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da aplicação.
- **CSS3:** estilização, cores, alinhamento e layout.
- **JavaScript:** lógica do contador e manipulação do DOM.
