# Interactive Counter | Contador Interativo

An interactive counter built with HTML, CSS, and JavaScript, featuring buttons to increase, decrease, and reset the displayed value, with continuous counting while a button is held down.

Um contador interativo desenvolvido com HTML, CSS e JavaScript, com botões para aumentar, diminuir e zerar o valor exibido, incluindo contagem contínua enquanto um botão permanece pressionado.

## Features | Recursos

- Increase, decrease, and reset the counter.
- Continuous counting while a button is held down.
- Buttons for interactive counter control.
- Botões para aumentar, diminuir e zerar o contador.
- Contagem contínua enquanto um botão permanece pressionado.
- Controle interativo por meio dos botões.

## Technologies | Tecnologias

- HTML5
- CSS3
- JavaScript

## Getting Started | Como executar

1. Clone this repository:
   ```
   git clone https://github.com/rafelolab/interactive-counter.git
   ```
2. Open the `Contador` folder.
3. Open `index.html` in your browser.

1. Clone o repositório:


3. Abra o arquivo `index.html` no navegador.
